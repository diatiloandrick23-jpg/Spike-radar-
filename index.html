    Alerts when the app is closed (10 min, once)
    1. Install the free ntfy app from the App Store. Tap Make a private topic above, copy it, and in ntfy tap + and subscribe to that exact topic.
    2. Tap Save and go live, then Send test to my phone. You should get a ping in ntfy.
    3. Open dash.cloudflare.com and make a free account. Go to Workers & Pages → Create → Create Worker, name it spike-radar, Deploy.
    4. Tap Edit code, delete everything, paste the whole worker.js file, then Deploy.
    5. Go to Storage & Databases → KV → Create a namespace named spike-radar.
    6. Back in the worker: Settings → Bindings → Add → KV namespace, variable name ALERTS, pick spike-radar.
    7. Settings → Variables and secrets: add FINNHUB_KEY (your key, type Secret), NTFY_TOPIC (your topic), APP_URL (this app’s link).
    8. Settings → Trigger events → Cron trigger: */2 * * * * (every 2 minutes).
    You’ll then get ±4% warnings, ±7% alerts, storm warnings and an hourly political news digest, even with your phone locked.
    Get your free keys
    1. Finnhub: finnhub.io → Get free API key → copy it from the dashboard.
    2. Twelve Data: twelvedata.com → Sign up → Dashboard → API Keys.
    3. Anthropic (optional): console.anthropic.com → API Keys → Create key, and add a few dollars of credit. Without it, news is scored by built-in rules.
    Keys are stored only on this phone.
